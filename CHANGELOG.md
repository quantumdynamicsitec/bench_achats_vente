# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/fr/1.0.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/lang/fr/).

## [1.0.0] - 2026-01-XX

### Ajouté
- Dashboard complet avec métriques en temps réel
- Onglet Tendances avec filtres par plateforme et période
- Onglet Électronique dédié aux composants PC (GPU, CPU, RAM, SSD)
- Onglet Alertes avec configuration personnalisable
- Agent IA conversationnel avec réponses contextuelles
- Onglet Méthodologie expliquant le pipeline d'analyse
- Filtres temporels : 7 jours, 30 jours, historique complet
- Données dynamiques mises à jour automatiquement (LIVE)
- Modales de détails pour chaque objet
- Graphiques interactifs (prix, volumes, catégories)
- Support multi-plateformes : Vinted, Leboncoin, eBay
- Stratégie Leboncoin : focus sur petits objets électroniques < 50€
- Analyse composants PC avec spécifications techniques
- Système de scoring (demande, compétition, confiance)
- Calcul ROI pour chaque opportunité
- Indicateurs de fiabilité par plateforme
- Documentation complète (README, CONTRIBUTING, LICENSE)

### Technologies
- React 18 + TypeScript
- Tailwind CSS
- Recharts pour les graphiques
- Lucide React pour les icônes
- Vite pour le build

## Format des Versions

- **Ajouté** : Nouvelles fonctionnalités
- **Modifié** : Changements dans les fonctionnalités existantes
- **Déprécié** : Fonctionnalités qui seront supprimées
- **Supprimé** : Fonctionnalités supprimées
- **Corrigé** : Corrections de bugs
- **Sécurité** : Corrections de vulnérabilités
